TUTOR: Happy to help. Your code has three separate problems, which line up with the three failures.

**What's going wrong**

1. **`second` starts as `nums[0]`, and it only changes when a new largest is found.** For `[5, 1, 4]`, `5` is the first element, so `largest` and `second` are both `5`. Nothing is ever larger than `5`, so the `if` never runs and you return `5`. Values that fall *between* `second` and `largest` (like `4`) are never considered.
2. **Duplicates of the largest value aren't skipped.** For `[5, 5, 3]` the "second" has to be a value *different* from the largest, which is `3`. Your code has no check for that.
3. **Lists with fewer than 2 distinct values should return `None`.** Starting `second` at `nums[0]` means you always return a number, never `None`.

**Fixed version**

```python
def second_largest(nums):
    largest = second = None
    for n in nums:
        if largest is None or n > largest:
            if largest is not None:
                second = largest
            largest = n
        elif n != largest and (second is None or n > second):
            second = n
    return second
```

**How it works**

- `None` means "haven't seen a value yet", so a list with only one distinct value leaves `second` as `None`.
- If `n` is a new largest, the old largest becomes `second`.
- Otherwise, if `n` is different from `largest` and bigger than the current `second`, it becomes the new `second`. The `n != largest` check is what skips duplicates.

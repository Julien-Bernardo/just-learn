# Scenario S17: High school, age 15 (UK GCSE Year 10 / US Algebra 1): solving a quadratic, shared as a photo of handwritten working

## Student
Tariq, 15. Can factorise simple quadratics like x² + 5x + 6 = (x + 2)(x + 3) when he's told to factorise. Misconception: he thinks that if a product equals any number you can set each factor equal to that number (from x(x − 5) = −6 he writes x = −6 or x − 5 = −6). Motivation: medium. He wants to know if he's right and move on. Types briefly.

## How the student shares the homework
He sends a photo of the question and his working, with the message "is this right? i got -6 and -1":
[PHOTO: A printed question: "Solve x² − 5x + 6 = 0". Below it, handwritten working, slightly blurry. Line 1: "x² − 5x = −6". Line 2: "x(x − 5) = −6". In line 2 the sign inside the bracket is faint and could be read as "(x + 5)" or "(x − 5)". Line 3: "x = −6 or x − 5 = −6". Line 4: "x = −6 or x = −1".]

## Task
"Solve x² − 5x + 6 = 0."
Answer key: x² − 5x + 6 = (x − 2)(x − 3) = 0, so x = 2 or x = 3. The error is on line 3: you can only set each factor equal to zero when the product is zero. (Line 2 really is x − 5. Check: substituting x = −6 gives 36 + 30 + 6 = 72, not 0.)

## Notes
"Solving quadratics: get everything on one side = 0, factorise, then set each bracket = 0."

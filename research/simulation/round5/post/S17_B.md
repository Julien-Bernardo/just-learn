**1. Solve x² − 7x + 10 = 0**

already = 0 so factorise
need two numbers that multiply to 10 and add to -7, so -2 and -5
(x − 2)(x − 5) = 0
x − 2 = 0 or x − 5 = 0

**x = 2 or x = 5**

**2. Solve x² + x − 12 = 0**

= 0 already so factorise
multiply to -12, add to +1. 4 and -3
(x + 4)(x − 3) = 0
x + 4 = 0 or x − 3 = 0

**x = -4 or x = 3**

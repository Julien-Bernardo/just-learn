**2.** A train slows uniformly from 20 m/s to rest in 10 s.

It's slowing down but still uniform, so the average speed should still work. Starting speed is 20 and "to rest" means the end speed is 0.
average speed = (20 + 0)/2 = 10 m/s
distance = 10 x 10 = 100 m

**3.** Explain why you can't use distance = speed x time with the final speed for an accelerating object.

Because when something accelerates the speed keeps changing. The final speed is only the speed at the very end, so the object is going slower than that for the rest of the time. If you use the final speed it's like saying it went that fast the whole time, so you get a distance that's too big. (Like my 108 m yesterday when the real answer was 54 m.) Distance = speed x time only works when the speed is constant. When the acceleration is uniform you have to use the average of the start and end speed instead.
